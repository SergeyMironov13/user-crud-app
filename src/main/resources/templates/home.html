User CRUD API

Добро пожаловать в систему управления пользователями!

Доступные endpoint:

🔓 Публичный (без авторизации):
GET /api/users/search/name?name={name} - Поиск пользователей по имени
🔒 Требует авторизации:
POST /api/users - Создать пользователя
GET /api/users - Получить всех пользователей
GET /api/users/{id} - Получить пользователя по ID
PUT /api/users/{id} - Обновить пользователя
DELETE /api/users/{id} - Удалить пользователя
DELETE /api/users - Удалить всех пользователей

Примеры запросов:

Публичный запрос (без авторизации):

curl "http://localhost:8080/api/users/search/name?name=Ivan"

Запрос с авторизацией:

curl -u user:password http://localhost:8080/api/users
